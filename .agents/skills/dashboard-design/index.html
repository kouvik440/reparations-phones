What this skill does

Teaches an AI agent to build complete, working dashboards — not just pretty screenshots. Every output includes real calculated data, wired-up interactions, and correct component states.

Outputs a single HTML file (Chart.js) or a React JSX component (Recharts) — you pick per prompt
Three style presets: dark-terminal (electric cyan on near-black), carbon-light (IBM Carbon Design System), and neutral-bw (pure Tailwind gray scale, black accent — works for any brand)
Motion system with easing tokens, duration tokens, hover states, entry animations, and skeleton loading — especially important for neutral-bw where color doesn't carry interactivity signals
Enforces correct KPI delta calculation from prior period data — no random numbers
Wires up pagination, sort indicators, empty states, and CSV export that actually works
Charts update in place on filter change — no destroy/recreate flicker

MistakeWhat the skill does instead

Static pagination HTMLWire tablePage state to click handlers dynamically
Destroy + recreate charts on filterchart.update('active') — smooth transition in place
Exporting full raw dataExport only the currently filtered dataset
Blank table on no resultsShow "No records match filters" empty state
Math.random() in visible outputPre-generate all data at init — never randomise on render
Non-negotiable rules
01
Layout order is always fixed
Sticky header → filter bar → KPI row → charts → table. Never put a chart above the KPIs.
02
All numbers use monospace font
KPI values, table cells, axis labels, badge text — everything numeric uses font-family: monospace. Proportional digits misalign in columns.
03
One update() function rules all filters
Every filter change calls a single update() that re-renders KPIs, all charts, and the table simultaneously. No partial updates.
04
KPI weight is light, not bold
Primary KPI value: font-weight 300. Large numbers in bold look cheap. Large numbers in light weight look premium.
05
Three component states minimum
Every data component needs: loading, empty-filtered, and live. Never design only the happy path.
Review checklist
Click to check off before shipping
KPI deltas are calculated from real prior period data
Pagination buttons have click handlers wired up
Empty state shows when filters return 0 results
CSV export downloads the filtered dataset, not full RAW
All numeric columns use monospace font
Charts use chart.update() — not destroy + recreate
Sort indicators update correctly (↑ ↓ ↕)
All charts have custom legends (Chart.js default disabled)
Table is horizontally scrollable on mobile
KPI grid collapses to 2-col at 768px
No Math.random() in any visible render path
Bar chart Y-axis starts at zero
Donut chart has 5 or fewer segments
Every interactive element has a visible hover state
Buttons animate on press (scale or translateY)
KPI counters animate up on load and filter change
neutral-bw: border color also shifts on hover (not just background)
